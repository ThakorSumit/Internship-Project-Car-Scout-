# 🚗 CarScout

CarScout is a full-stack web application that simplifies the process of buying and selling used cars. The platform enables buyers to search, compare, and inspect vehicles, while sellers can list cars and manage their listings through a dedicated dashboard. The system also integrates AI-powered vehicle inspection reports to help users make informed purchasing decisions.

## ✨ Features

### 👤 Authentication
- User Registration & Login
- Role-Based Access (Buyer, Seller, Admin)
- Secure Authentication

### 🚘 Buyer Features
- Browse available cars
- Advanced search and filtering
- Compare multiple cars
- View detailed vehicle specifications
- AI-generated inspection reports
- Add cars to Wishlist
- Make offers to sellers
- Book test drives
- Set price alerts
- Secure online payments with Razorpay

### 🚙 Seller Features
- Add, edit, and delete car listings
- Upload vehicle images
- Manage offers from buyers
- View listing status
- Receive AI-generated inspection reports

### 🛠️ Admin Features
- Manage users
- Review and approve/reject listings
- Manage vehicle categories
- Monitor AI inspection reports
- Dashboard for overall platform management

### 🤖 AI Integration
- AI-powered vehicle inspection reports
- Vehicle condition scoring (0–10)
- Risk assessment
- Buyer recommendations
- Mileage analysis
- Price analysis
- Accident impact analysis
